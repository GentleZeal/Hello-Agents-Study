# Task 05：基于低代码平台的智能体搭建

学习材料：[Hello-Agents 第五章](https://github.com/datawhalechina/hello-agents/tree/main/docs/chapter5)。

## 什么是低代码智能体平台

低代码平台用可视化界面配置模型、提示词、知识库、工具和工作流，让开发者通过组合现有组件搭建应用。它能减少基础代码量，但仍需要明确目标、理解数据来源、测试结果并处理失败情况。

## 平台与构成

- Coze（扣子）：通过界面配置智能体、提示词和工具，适合体验可视化创建。
- Dify：提供应用编排、知识库和模型接入等能力，可用于构建 LLM 应用。
- FastGPT：侧重知识库问答，也支持工作流。
- n8n：通用工作流自动化工具，可以把 AI 节点与其他服务连接。

模型负责生成内容；提示词描述任务和行为要求；工具让系统与外部服务交互；知识库提供可检索资料；工作流把步骤按指定逻辑连接。不是每个简单应用都需要所有组件。

## Workflow 与 Agent

工作流通常按预设节点和条件执行；智能体可以根据目标和当前信息选择下一步，但其自主程度取决于实际配置。实践中可以把可预测的步骤交给固定工作流，把需要理解或决策的部分交给模型，并对结果进行检查。

## 实践记录

使用扣子编程以自然语言创建“AI概念讲解智能体”，要求其面向初学者、举例解释并提出自测问题。在预览区域输入“请用简单例子解释什么是智能体，它和大语言模型有什么区别？”，助手返回了解释、生活例子及自测问题。[查看实操截图](实操截图.png)。本次是在预览中测试，未进行公开部署。

回答中的“自动下单付款”是描述一种假想的智能体能力，不意味着本次助手实际具备该能力；真实执行还需要相应工具、权限及适当的用户确认。大语言模型也不只是静态知识库，本例是帮助理解两者关系的简化类比。

## 收获与注意

搭建智能体需要明确用途、设置模型和提示、测试输入输出，并对回答的准确性与隐私进行检查。平台输出不一定正确；不能因使用了智能体或知识库就省略验证。
