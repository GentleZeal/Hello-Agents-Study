# Task 04：智能体经典范式

学习材料：[Hello-Agents 第四章](https://github.com/datawhalechina/hello-agents/tree/main/docs/chapter4)。

## 三种范式

| 范式 | 核心步骤 | 适用思路 | 注意点 |
| --- | --- | --- | --- |
| ReAct | 思考 → 行动 → 观察 → 根据反馈继续，最后结束 | 需要查询外部信息、逐步调整的任务 | 工具失败、格式错误或循环次数过多都可能导致失败 |
| Plan-and-Solve | 先拆解并形成计划 → 逐步执行 → 输出结果 | 可分解成多个有序步骤的问题 | 初始计划可能不合理，执行结果仍需核查 |
| Reflection | 初稿 → 审查反馈 → 修改 → 再评估 | 代码或文章等可以迭代改进的任务 | 自我评审不一定可靠，多轮调用增加时间与成本 |

ReAct 像边搜索边调整；Plan-and-Solve 像先写步骤再逐个完成；Reflection 像写完初稿后进行审阅和修订。三者可以结合使用，输出过程不保证结论正确。

## 实践记录

在教材第四章的示例副本中沿用 Task00 的模型配置。ReAct 的搜索接口适配为 Task00 已使用的 Tavily；Plan-and-Solve 和 Reflection 使用教材中的示例类。实践结果以实际终端输出和截图为准。

- ReAct：观察 Thought、Action、工具返回的 Observation 和最终答案。
- Plan-and-Solve：观察生成的计划、逐步执行的结果和最终答案；苹果题可手算 15 + 30 + 25 = 70，检查模型结果。
- Reflection：观察初始代码、审查反馈、修改后的代码；自评“无需改进”不等于经过测试。

本次实践中，[ReAct](ReAct运行截图.png) 成功调用 Tavily，得到搜索观察并输出最终答案；[Plan-and-Solve](Plan-and-Solve运行截图.png) 生成计划并算出 70。Reflection 首次运行遇到在线模型试用次数限制；改用本地 Qwen3 0.6B 后，实际产生了初稿、反思、优化和最终输出（[过程 1](Reflection-1.png)、[过程 2](Reflection-2.png)、[过程 3](Reflection-3.png)、[过程 4](Reflection-4.png)）。

不过，Reflection 的最终素数函数仍有明显错误：它把 0、1 初始化为素数，并未排除 2 以外的所有偶数。例如 n=4 时，它会错误返回 [0, 1, 2, 3, 4]，正确结果应为 [2, 3]。这说明反思循环成功执行，并不代表生成的代码正确；还需要运行测试和人工审查。
